# Egging On Co-op

Кооператив для [Egging On](https://store.steampowered.com/app/2897610/Egging_On/) на 2–4 игроков: яйца друзей в вашем мире,
общий мир (предметы, бутылки, платформы, события, площадки дрона), телепорт к другу, эмоции и метки, доска позора.
Подключение по коду приглашения, через Radmin VPN или по IP.

## Установка

1. Скачайте `EggCoop-<версия>.zip` из [Releases](../../releases).
2. Распакуйте куда угодно и запустите **`Установить.bat`**.
   Скрипт сам найдёт игру в Steam (или попросит выбрать папку с `Egging On.exe`), поставит загрузчик модов
   [BepInEx 5.4.23.5](https://github.com/BepInEx/BepInEx) — он уже лежит в архиве — и сам мод.
   Ваши настройки и другие моды не трогаются.
3. В игре нажмите **F9**.

Обновление — тем же `Установить.bat` из нового архива. Удаление — `Удалить.bat`.
У всех игроков должна быть одна и та же версия мода. Подробности — в `Инструкция.txt` внутри архива.

## Управление

| Клавиша | Что делает |
|---|---|
| F9 | окно кооператива: создать игру / подключиться, настройки хоста, игроки, доска позора, клавиши |
| T | телепорт к другу (при 2+ друзьях — выбор цифрой) |
| G (зажать) | колесо эмоций: навести мышь и отпустить, × в центре — закрыть |
| колёсико мыши | метка там, куда смотрит камера |

## Сборка из исходников

Нужны .NET SDK 8+ и установленная игра с BepInEx 5 (сборка ссылается на её `Assembly-CSharp.dll` и др.;
сами файлы игры в репозиторий не входят).

```bash
dotnet build src/EggCoop -c Release -p:GameDir="C:/Program Files (x86)/Steam/steamapps/common/Egging On"
dotnet run --project src/SelfTest
```

`tools/lab.ps1 pack` собирает архив для раздачи (`dist/EggCoop-<версия>.zip`, BepInEx скачивается и проверяется по SHA-256).
`tools/lab.ps1 up` запускает две копии игры на одном ПК для тестов (папки `lab/p1`, `lab/p2`, `-c Lab`); `NOTES.md` — журнал
решений и проверок.
